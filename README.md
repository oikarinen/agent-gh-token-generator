# GitHub App CLI Authentication Helper

This tool provides a secure and convenient way to authenticate the official GitHub CLI (`gh`) as a GitHub App installation. It automates the complex token generation process, allowing you to perform operations on repositories as a specific App instead of as your personal user.

## The Approach (Why This Architecture?)

The primary goal is to securely authenticate the `gh` CLI using the short-lived tokens generated by a GitHub App. This avoids using personal access tokens (PATs) or other long-lived credentials for automated tasks.

The GitHub App authentication flow is complex:

1.  A secure JSON Web Token (JWT) must be created and signed with the App's private key.
2.  This JWT is sent to the GitHub API.
3.  GitHub responds with a temporary, short-lived **installation access token**.
4.  This final token is what can be used to authenticate.

This process is difficult to perform in a simple shell script, especially the cryptographic (JWT signing) step. To solve this, we use a hybrid approach that separates the complex logic from the user-facing configuration.

1.  **The Go Program (`gh-app-token-generator`)**
    This is the core of the tool. It's a compiled, self-contained program that handles all the security-sensitive operations:
    *   Securely retrieves your App's private key from the macOS Keychain.
    *   Generates the signed JWT.
    *   Calls the GitHub API to exchange the JWT for an installation access token.
    *   Prints the final token to standard output.

    **Go was chosen** because it compiles to a single, dependency-free binary. This makes the tool robust, fast, and secure, without forcing the user to manage runtime dependencies like with Python or Node.js. It's the perfect language for a hardened, reusable utility.

2.  **The Shell Script (`agent-github-token`)**
    This is the user-friendly wrapper you interact with. Its job is to:
    *   Hold your specific configuration (your App ID and Installation ID).
    *   Perform pre-flight checks to ensure all tools are installed.
    *   Call the Go program with the correct arguments.
    *   Pipe the resulting token to `gh auth login`.

This separation means the core logic can eventually be open-sourced without exposing any configuration, while the wrapper script remains a simple, easily configurable entrypoint.

## Prerequisites

*   **macOS:** Required for the `security` CLI and Keychain integration.
*   **GitHub CLI (`gh`):** The tool this script authenticates. ([Installation Guide](https://github.com/cli/cli#installation))

## Setup Guide

Follow these steps to create your GitHub App and configure this tool.

### Step 1: Create a GitHub App

1.  Navigate to your GitHub **Settings**.
2.  Go to **Developer settings** > **GitHub Apps**.
3.  Click **New GitHub App**.
4.  Fill out the form:
    *   **GitHub App name:** Give it a descriptive name (e.g., "My Local Repo Agent").
    *   **Homepage URL:** A placeholder is fine (e.g., `https://your-app-homepage.com`).
    *   **Webhook:** Uncheck **Active**.
    *   **Repository permissions:** Grant the permissions your app will need. For example, if you need to clone repositories, grant `Contents: Read-only`. Start with the minimum permissions required.
5.  Click **Create GitHub App**.
6.  On the next page, make a note of the **App ID**. You'll need it later.

### Step 2: Generate and Store a Private Key

1.  On your App's settings page, scroll down to the "Private keys" section.
2.  Click **Generate a private key**. A `.pem` file will be downloaded immediately.
3.  **Treat this file as a secret.** To avoid corrupting the multi-line PEM when passing it through the shell, first base64-encode it and then store that base64 string securely in the macOS Keychain, replacing the path with the actual path to your downloaded file:

    ```bash
    GH_APP_PRIVATE_KEY_B64="$(base64 -b 0 -i /path/to/your-downloaded-private-key.pem)"
    security add-generic-password \
      -a "GH_APP_PRIVATE_KEY" \
      -s "agent-github-token" \
      -w "$GH_APP_PRIVATE_KEY_B64"
    ```

### Step 3: Install the App in a Repository

1.  In your App's settings, click **Install App** in the left sidebar.
2.  Click **Install** next to your user or organization account.
3.  Choose which repositories the App should have access to ("All repositories" or "Only select repositories").
4.  After installation, you will be redirected to an installations page. The URL will look like `https://github.com/settings/installations/12345678`.
5.  That final number in the URL is your **Installation ID**. Make a note of it.

### Step 4: Download and Configure the Tool

1.  **Download the latest release:**
    Go to the [GitHub Releases page](https://github.com/oikarinen/agent-gh-token-generator/releases) for this repository. Since this tool currently only supports macOS, download the macOS (darwin) archive (e.g., `..._darwin_...tar.gz`).

2.  **Extract the archive:**
    Unpack the `.tar.gz` file. It will create a directory containing the `gh-app-token-generator` binary and a `bin/agent-github-token` script (the binary is typically at the archive root, while the script is inside `bin/`). Ensure that the `gh-app-token-generator` binary is placed alongside the `bin/agent-github-token` script (for example, by moving the binary into the `bin/` directory, or by moving both files into a common directory in your cloned repository) so that the script can find the helper binary when it runs.

3.  **Configure the wrapper script:**
    Edit the `bin/agent-github-token` file and replace the placeholder values at the top of the script with your **App ID** and **Installation ID**.

    ```bash
    # In bin/agent-github-token
    GH_APP_ID="<Your-App-ID>"
    GH_APP_INSTALLATION_ID="<Your-Installation-ID>"
    ```

### Step 5: Run the Authenticator

You are now ready to authenticate.

```bash
# Make the script executable (only needed once)
chmod +x bin/agent-github-token

# Run the script to log in
./bin/agent-github-token
```

The script will now generate a token and use it to log the `gh` CLI in. You can verify this by running `gh auth status`.
